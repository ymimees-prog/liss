# Liss — бот для челленджа «90 тяжёлых дней»

Личный Telegram-бот: учёба, колледж, IT-развитие, режим дня, эмоции и деньги в одном месте.

## Что умеет

| Раздел | Что внутри |
|---|---|
| 📅 **Сегодня** | День N из 90 и чек-лист: подъём, колледж, еда, настроение, ≥1 ч IT, повторения, финансы |
| 📊 **Прогресс** | Шкала челленджа, серии дней, посещаемость, часы на IT, копилка, отчёт за 7 дней и наблюдения (например, как время подъёма влияет на настроение) |
| 📚 **Учёба** | Темы колледжа и IT: «надо изучить» → «на повторении» → «выучено навсегда». Интервальные повторения: 1, 3, 7, 14, 30, 60 дней. «Забыла» — тема возвращается на начало |
| 🏫 **Колледж** | Отметка посещаемости (была / опоздала / пропустила / уважительная), процент и полоска за 14 дней |
| 💻 **IT-развитие** | Учёт времени по навыкам (Python, Git/GitHub, SQL, алгоритмы…), серия дней, стартовый роадмап Python + GitHub на 22 темы |
| 🌅 **Дневник дня** | Подъём одной кнопкой, приёмы пищи, настроение 1–5, эмоции, заметка о дне |
| 💰 **Финансы** | Доходы, расходы по категориям, копилка, цель накоплений с прогрессом, правило 50/30/20 на каждый доход, отчёт за месяц с советами, удаление ошибочных записей |

Напоминания: утром (день челленджа, вехи 7/30/45/60/90, сколько тем повторить) и вечером (что ещё не отмечено).

## Запуск

1. Создай бота у [@BotFather](https://t.me/BotFather) и получи токен.
2. Узнай свой Telegram ID у [@userinfobot](https://t.me/userinfobot) — чтобы бот отвечал только тебе.
3. Установи и запусти:

```bash
python3 -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env               # и впиши BOT_TOKEN и ALLOWED_USERS
python -m bot
```

Бот работает, пока запущен процесс. Чтобы он жил 24/7 (и присылал напоминания), запусти его на сервере/VPS
или бесплатном хостинге вроде PythonAnywhere / Railway. Данные хранятся в SQLite-файле `liss.db`.

## Команды

- `/start` — меню, `/help` — справка, `/week` — прогресс, `/cancel` — отменить ввод
- `/morning 07:00`, `/evening 21:30` — время напоминаний
- `/tz Europe/Moscow` — часовой пояс
- `/startday 2026-11-01` — дата старта челленджа (по умолчанию — день первого сообщения)

## Разработка

```bash
pip install -r requirements-dev.txt
pytest
```

Структура: `bot/logic.py` — чистая логика (повторения, финансы, парсинг), `bot/db.py` — SQLite,
`bot/handlers/` — разделы меню, `bot/reminders.py` — напоминания. `tests/test_bot_flow.py`
прогоняет реальный диспетчер на фейковых апдейтах Telegram.
