# Akia — бот для крипты и трейдинга

Личный Telegram-бот: курсы и графики, портфель, дневник сделок, калькулятор риска и обучение.

## Что умеет

| Раздел | Что внутри |
|---|---|
| ☀️ **Сводка** | Курсы доллара, USDT и крипты, открытые сделки с текущим результатом, портфель, что повторить, совет. Каждое утро приходит сама вместе с темой дня (`/digest 09:00`, `/digest off`) |
| 📈 **Рынок** | Курсы ЦБ (доллар, евро, юань) и крипты (USDT в рублях, BTC, ETH, TON, SOL, BNB, XRP), насколько USDT дороже официального доллара. По каждому активу — график за неделю/месяц/3 месяца/год со скользящими средними и мгновенный разбор: тренд, RSI, поддержка/сопротивление, волатильность. Уведомления «напиши, когда USDT будет 100 ₽». Данные: ЦБ РФ и CoinGecko, бесплатно |
| 💼 **Портфель** | Покупки и продажи монет, средняя цена, стоимость сейчас, прибыль/убыток (в $ и ₽), зафиксированный результат |
| 📓 **Сделки** | Дневник демо и реальных сделок: вход, стоп, цель, причина. Риск и соотношение прибыль/риск при открытии, результат в $ и R при закрытии, выводы и эмоции. Статистика: % прибыльных, средний R, профит-фактор |
| 🧮 **Калькулятор** | Размер позиции по депозиту, % риска, входу и стопу; предупреждает про плечо и риск больше 2% |
| 🎓 **Обучение** | 19 встроенных уроков по крипте и трейдингу (кошельки, P2P и безопасность, спот/фьючерсы, ордера, индикаторы, риск-менеджмент, психология, налоги, мошенники…), тема дня, интервальные повторения, свои темы. Кнопка «🤖 Объясни подробнее» — через Claude, если добавить ключ |

## Запуск

1. Создай бота у [@BotFather](https://t.me/BotFather) и получи токен.
2. Узнай свой Telegram ID у [@userinfobot](https://t.me/userinfobot) — чтобы бот отвечал только тебе.
3. Самый простой запуск — скачай проект и:
   - **Windows:** дважды кликни `start.bat` (нужен Python с python.org, галочка «Add Python to PATH»)
   - **Mac / Linux / Android (Termux):** `sh start.sh`

   При первом запуске скрипт создаст `.env` — впиши туда токен и свой ID и запусти ещё раз.

   Или вручную:

```bash
python3 -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env               # и впиши BOT_TOKEN и ALLOWED_USERS
python -m bot
```

На ноутбуке бот работает, пока он включён. **Бесплатно 24/7** — на PythonAnywhere, пошаговая инструкция: [HOSTING.md](HOSTING.md). Данные хранятся в SQLite-файле `liss.db`.

## Команды

- `/start` — меню, `/help` — справка, `/cancel` — отменить ввод
- `/digest 09:00` — время утренней сводки, `/digest off` — выключить
- `/tz Europe/Moscow` — часовой пояс

## Разработка

```bash
pip install -r requirements-dev.txt
pytest
```

Структура: `bot/logic.py` — формулы (риск, позиция, портфель, статистика), `bot/market.py` — курсы,
разбор и графики, `bot/lessons.py` — уроки, `bot/db.py` — SQLite, `bot/handlers/` — разделы меню,
`bot/reminders.py` — утренняя сводка и уведомления о цене, `bot/web.py` — режим для хостинга.
`tests/` прогоняют реальный диспетчер на фейковых апдейтах Telegram и образцах ответов API.
